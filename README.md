# Linux Server Implementation

## Overview

An academic project covering the implementation and configuration of Linux server services, including DNS, MySQL Database, and Mail Server.

## Technologies

* Ubuntu Server
* BIND9
* MySQL
* Fedora Linux
* Postfix
* Dovecot
* SpamAssassin

## Project Scope

The project covers:

* DNS server configuration and testing
* MySQL database server configuration and security
* Mail server configuration and testing
* Basic server security and access control

## Documentation

The project presentation contains the implementation steps, configurations, security measures, testing procedures, and references.

## Academic Project

Developed as part of an Information Technology academic course.
